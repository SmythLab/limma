limma is available as part of Bioconductor, see: <https://bioconductor.org/packages/limma>.
Questions about limma can be sent to the Bioconductor support forum at https://support.bioconductor.org.

This repository is used to host limma documentation.
The following vignettes and example analyses using are available:

* [limma User's Guide (pdf)](https://bioconductor.org/packages/release/bioc/vignettes/limma/inst/doc/limmaUsersGuide.pdf)
* [Datasets used in the limma User's Guide](https://bioinf.wehi.edu.au/limma/index.html)
* [limma Reference Manual (pdf)](https://bioconductor.org/packages/release/bioc/manuals/limma/man/limma.pdf)
* [RNA-seq analysis is easy as 1-2-3 with limma, Glimma and edgeR](https://bioconductor.org/packages/release/workflows/vignettes/RNAseq123/inst/doc/limmaWorkflow.html)
* [GSE118337: example analysis with human Agilent microarrays](https:/smythlab.github.io/limma/GSE118337.html)
